# Work Authorization Questions: Complete Guide

This document provides a comprehensive analysis of work authorization questions in job applications and how to handle them correctly in the auto-apply system.

---

## 1. Question Variations

Work authorization questions appear in various forms. Here is an exhaustive list grouped by intent.

### 1.1 Current Authorization Questions

These ask whether you can legally work in the US right now.

| Question Variation | Format |
|-------------------|--------|
| Are you authorized to work in the United States? | Yes/No |
| Are you legally authorized to work in the U.S.? | Yes/No |
| Do you have the legal right to work in the United States? | Yes/No |
| Are you currently authorized to work in the US for any employer? | Yes/No |
| Are you authorized to work lawfully in the United States? | Yes/No |
| Can you legally work in the United States? | Yes/No |
| Do you have valid work authorization? | Yes/No |

### 1.2 Sponsorship Requirement Questions

These ask whether you will need the company to sponsor a work visa.

| Question Variation | Format |
|-------------------|--------|
| Do you require visa sponsorship to work in the United States? | Yes/No |
| Will you require sponsorship now or in the future? | Yes/No |
| Will you now or in the future require visa sponsorship? | Yes/No |
| Do you need sponsorship for a work visa? | Yes/No |
| Will you require employment visa sponsorship? | Yes/No |
| Do you require any visa sponsorship? | Yes/No |
| Would you require visa sponsorship to continue working in the US? | Yes/No |
| Will you now or will you in the future require employment visa sponsorship? | Yes/No |
| Do you or will you require sponsorship for a US employment visa (e.g., H-1B)? | Yes/No |

### 1.3 Citizenship/Residency Status Questions

These ask directly about your immigration status.

| Question Variation | Format |
|-------------------|--------|
| Are you a US citizen or permanent resident? | Yes/No |
| What is your current visa/immigration status? | Dropdown |
| Please select your employment eligibility status | Dropdown |
| What is your work authorization status? | Dropdown |
| Are you a citizen of the United States? | Yes/No |
| What is your citizenship status? | Dropdown |
| Are you a U.S. Citizen, U.S. Permanent Resident, or otherwise have work authorization? | Yes/No |

### 1.4 Security Clearance / Export Control Questions

Certain positions (defense, government contractors) have stricter requirements.

| Question Variation | Format |
|-------------------|--------|
| Are you a US citizen or US national? | Yes/No |
| Are you a US Person as defined by ITAR? | Yes/No |
| Do you meet the requirements for a security clearance? | Yes/No |
| Can you satisfy the requirements of 8 U.S.C. 1324b(a)(3)? | Yes/No |

**Note**: For ITAR/EAR compliance, "US Person" includes US citizens, permanent residents (green card holders), and refugees/asylees. It does NOT include H-1B, OPT, or other temporary visa holders.

### 1.5 Time-Limited Questions

| Question Variation | Format |
|-------------------|--------|
| How long are you authorized to work in the US? | Text/Dropdown |
| When does your current work authorization expire? | Date |
| Do you have at least 12 months of remaining work authorization? | Yes/No |

## 2. Correct Answers by Immigration Status

### 2.1 US Citizens

| Question Type | Answer |
|--------------|--------|
| Authorized to work in US? | **Yes** |
| Require sponsorship? | **No** |
| Citizen or permanent resident? | **Yes** |
| US Person (ITAR)? | **Yes** |
| Status dropdown | "US Citizen" |

### 2.2 Permanent Residents (Green Card Holders)

| Question Type | Answer |
|--------------|--------|
| Authorized to work in US? | **Yes** |
| Require sponsorship? | **No** |
| Citizen or permanent resident? | **Yes** |
| US Person (ITAR)? | **Yes** |
| Status dropdown | "Permanent Resident" or "Green Card Holder" |

### 2.3 F-1 Students on OPT (Optional Practical Training)

| Question Type | Answer |
|--------------|--------|
| Authorized to work in US? | **Yes** (while OPT is valid) |
| Require sponsorship? | **Yes** (eventually - critical to disclose) |
| Citizen or permanent resident? | **No** |
| US Person (ITAR)? | **No** |
| Status dropdown | "OPT" or "Work Visa" |

**Important nuances for OPT:**
- Standard OPT: 12 months
- STEM OPT Extension: Additional 24 months (36 months total)
- OPT gives current authorization but requires future H-1B sponsorship for long-term employment
- Answering "No" to sponsorship is technically false and could be considered fraud

### 2.4 F-1 Students on CPT (Curricular Practical Training)

| Question Type | Answer |
|--------------|--------|
| Authorized to work in US? | **Yes** (while CPT is valid) |
| Require sponsorship? | **Yes** |
| Citizen or permanent resident? | **No** |
| US Person (ITAR)? | **No** |
| Status dropdown | "CPT" or "Work Visa" |

**Note**: CPT is authorized through the school and tied to curriculum. Full-time CPT for 12+ months affects OPT eligibility.

### 2.5 H-1B Visa Holders

| Question Type | Answer | Notes |
|--------------|--------|-------|
| Authorized to work in US? | **Yes** | |
| Require sponsorship? | **Yes** (unless Green Card pending) | H-1B transfer required |
| Citizen or permanent resident? | **No** | |
| US Person (ITAR)? | **No** | |
| Status dropdown | "H-1B" | |

**H-1B Transfer considerations:**
- Can transfer H-1B to new employer
- New employer must file H-1B petition
- This counts as "sponsorship" even if already on H-1B
- H-1B cap-exempt if already counted against cap

### 2.6 H-4 EAD Holders (H-1B Dependent Spouses)

| Question Type | Answer |
|--------------|--------|
| Authorized to work in US? | **Yes** (with valid EAD) |
| Require sponsorship? | **Yes** |
| Citizen or permanent resident? | **No** |
| Status dropdown | "Work Visa" or "EAD" |

### 2.7 L-1 Visa Holders

| Question Type | Answer |
|--------------|--------|
| Authorized to work in US? | **Yes** |
| Require sponsorship? | **Yes** (for new employer) |
| Citizen or permanent resident? | **No** |

### 2.8 TN Visa Holders (USMCA/NAFTA)

| Question Type | Answer |
|--------------|--------|
| Authorized to work in US? | **Yes** |
| Require sponsorship? | **Yes** (TN renewal needed) |
| Citizen or permanent resident? | **No** |

**Note**: TN is employer-specific. New employer must apply for new TN or different visa category.

### 2.9 Refugees and Asylees

| Question Type | Answer |
|--------------|--------|
| Authorized to work in US? | **Yes** |
| Require sponsorship? | **No** |
| Citizen or permanent resident? | **No** (but can say "Yes" if question is about eligibility) |
| US Person (ITAR)? | **Yes** (Refugees/asylees qualify as US Persons) |

### 2.10 DACA Recipients

| Question Type | Answer |
|--------------|--------|
| Authorized to work in US? | **Yes** (with valid EAD) |
| Require sponsorship? | **No** (but status is temporary) |
| Citizen or permanent resident? | **No** |
| Status dropdown | "DACA" or "Work Visa" |

**Note**: DACA provides work authorization but no path to permanent residency through employment. Legal landscape is complex.

## 4. Red Flags and Compliance

### 4.1 What Constitutes Fraud

**NEVER misrepresent immigration status.** The following are considered fraudulent:

1. **Claiming no sponsorship needed when on OPT/H-1B**
   - OPT holders WILL need sponsorship eventually
   - H-1B holders need transfer (which is sponsorship)

2. **Claiming to be a US Person when not**
   - For ITAR-controlled positions, this is a federal offense

3. **Hiding visa expiration dates**
   - If authorization is expiring soon, disclosure is required

### 4.2 System Safeguards

The auto-apply system should:

1. **Require users to confirm their status is accurate**
2. **Warn users about positions requiring US Person status**
3. **Never auto-apply to ITAR positions for non-US Persons**
4. **Track visa expiration and warn about limited authorization**

### 4.3 What We Should Skip

Do not auto-apply to positions with these requirements unless user qualifies:
- "Must be a US Citizen"
- "Security clearance required"
- "ITAR/EAR restricted"
- "US Persons only"
- "No sponsorship available"

```javascript
    "canWorkForAnyEmployer": true,      // Some visas are employer-specific
    
    // Overrides (auto-calculated from status but can be manually set)
    "currentlyAuthorizedOverride": null,
    "requiresSponsorshipOverride": null
  }
}
```

### 5.2 Helper Functions

```javascript
function getWorkAuthAnswers(profile) {
  const status = profile.workAuthorization?.status || inferFromLegacy(profile);
  const mapping = STATUS_MAPPING[status];
  
  if (!mapping) {
    throw new Error(`Unknown status: ${status}`);
  }
  
  return {
    authorizedToWork: mapping.currentlyAuthorized ? "Yes" : "No",
    requiresSponsorship: mapping.requiresSponsorship ? "Yes" : "No",
    isUSPerson: mapping.isUSPerson,
    statusLabel: mapping.statusLabel,
    
    // For complex questions
    citizenOrPR: ["us_citizen", "permanent_resident"].includes(status) ? "Yes" : "No",
  };
}

// For legacy profile support
function inferFromLegacy(profile) {
  if (profile.workAuth === "Yes" && profile.workAuthRequired === false) {
    return "us_citizen";  // Assume citizen if authorized + no sponsorship
  }
  if (profile.workAuth === "Yes" && profile.workAuthRequired === true) {
    return "opt";  // Assume OPT if authorized + needs sponsorship
  }
  return "unknown";
}
```

## 6. ATS Integration Updates

### 6.1 Question Pattern Matching

```javascript
const WORK_AUTH_PATTERNS = {
  // Questions about current authorization
  currentAuth: [
    /authorized.*work/i,
    /legally.*authorized/i,
    /legal.*right.*work/i,
    /can.*legally.*work/i,
    /valid.*work.*authorization/i,
  ],
  
  // Questions about sponsorship
  sponsorship: [
    /require.*sponsorship/i,
    /need.*sponsorship/i,
    /visa.*sponsorship/i,
    /employment.*visa.*sponsorship/i,
    /will.*require.*sponsorship/i,
    /now.*or.*future.*sponsorship/i,
  ],
  
  // Direct citizenship questions
  citizenship: [
    /citizen.*permanent.*resident/i,
    /citizenship.*status/i,
    /immigration.*status/i,
    /employment.*eligibility/i,
    /us.*citizen/i,
  ],
  
  // ITAR/Clearance questions
  itar: [
    /itar/i,
    /us.*person/i,
    /export.*control/i,
    /security.*clearance/i,
    /8.*u\.s\.c/i,
  ],
};
```

### 6.2 Answer Selection

```javascript
async function handleWorkAuthQuestion(page, question, profile) {
  const answers = getWorkAuthAnswers(profile);
  const questionLower = question.toLowerCase();
  
  // Match question type and provide appropriate answer
  if (WORK_AUTH_PATTERNS.currentAuth.some(p => p.test(question))) {
    return answers.authorizedToWork;
  }
  
  if (WORK_AUTH_PATTERNS.sponsorship.some(p => p.test(question))) {
    return answers.requiresSponsorship;
  }
  
  if (WORK_AUTH_PATTERNS.citizenship.some(p => p.test(question))) {
    return answers.citizenOrPR;
  }
  
  if (WORK_AUTH_PATTERNS.itar.some(p => p.test(question))) {
    return answers.isUSPerson ? "Yes" : "No";
  }
  
  // Status dropdown
  if (/status|select.*eligibility/i.test(question)) {
    return answers.statusLabel;
  }
  
  return null;  // Unknown question type
}
```

## 7. Summary

### Key Takeaways

1. **Always be truthful** - Misrepresenting immigration status is fraud
2. **OPT/H-1B = Sponsorship Required** - Even though currently authorized
3. **US Person != US Citizen** - Includes PRs and refugees
4. **Track expirations** - Time-limited authorization matters
5. **Skip incompatible jobs** - Don't waste applications on ITAR positions

### Data We Need From Users

| Field | Type | Required | Purpose |
|-------|------|----------|---------|
| status | enum | Yes | Immigration category |
| expirationDate | date | If applicable | Track authorization window |
| statusLabel | string | Derived | Dropdown answer |

### Current Profile Gaps

The existing `workAuth` and `workAuthRequired` fields are too simplistic. We need:
1. Explicit status enum
2. Expiration tracking
3. US Person flag for ITAR positions
4. Better pattern matching in fillers
